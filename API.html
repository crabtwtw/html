照著做大約 5 分鐘。先在 BingX 建一組 API，再到跟單申請頁貼上，驗證通過就自動開通。圖上的黃色圈是要點的地方。

BingX App→建立 API→Telegram 拿 ID→bot.chaho.com.tw/join→貼上開通
開始前準備
  • BingX 帳戶要用團隊邀請連結註冊（不是團隊的帳戶會被擋下）。
  • BingX 帳戶已完成身分驗證，並綁好 Google 驗證（建立 API 時要輸入驗證碼）。
  • 手機有裝 Telegram。

步驟 3

權限只勾「合約交易」

「讀取」通常預設就有勾。再勾 永續合約交易，其他都不用勾。

千萬不要勾「提幣」。機器人只需要下單，不需要提幣權限；不勾提幣，就算 API 外流也沒辦法把錢領走。

步驟 10

開通完成，回 Telegram 設定跟單

看到 「開通完成」 就好了，機器人也會傳訊息通知你。回到 Telegram 機器人，點下方 「🌐 網頁登入」，就能設定每筆金額和槓桿。

建議一開始「每筆金額」先設 2U，跑幾筆熟悉之後再慢慢調高。新開通的帳號預設是「手動確認」：訊號來時機器人先問你，按 ✅ 才下單。
常見問題

卡住的話看這裡

顯示「BingX 驗證失敗」

最常見是 IP 白名單沒填，或填錯。回到 BingX 的 API 管理，確認 IP 是 107.191.52.90。也可能是 Key 複製不完整（前後多了空格），重新複製再貼一次。

顯示「金鑰正確，但讀不到合約帳戶」

這把 API 沒有勾「永續合約交易」。刪掉重建一把，記得勾合約交易。也請確認你的 BingX 已經開通合約帳戶。

顯示「非此團隊 UID，無法申請」

這個 BingX 帳戶不是用團隊邀請連結註冊的。請洽客服，用團隊的邀請連結註冊後再申請。

驗證碼一直收不到

先確認有在 Telegram 打開 @bingxB_bot 按過「開始」，再回到申請頁重新按「取得驗證碼」。同一個 ID 一分鐘只能寄一次。

Secret Key 忘記複製

Secret Key 只會出現一次。到 BingX 的 API 管理把那把 API 刪掉，重新建立一把，這次兩串都先複製到備忘錄。

顯示「已送出申請」而不是「開通完成」

驗證都通過了，只是目前名額需要人工開通，開通後會在 Telegram 通知你，不用再申請一次。

建 API 時只開合約交易、不要開提幣。API Key 和 Secret Key 只貼在 bot.chaho.com.tw/join，不要傳給任何人。合約交易有槓桿，可能虧損本金，建議每筆先從 2U 開始。
