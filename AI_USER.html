2這個指標會幫你做什麼

① 判斷方向

用一條「範圍過濾」趨勢線，濾掉小雜訊，告訴你現在偏漲還是偏跌。

② 標漲跌點

方向一翻轉就標漲／跌，當作進出場的參考時機。

③ 看力道

用顏色深淺表示這根K的強弱，亮=強、暗=弱，一眼判斷動能。

④ 抓頂底

在大波段的頂、底標⭐，提醒可能的轉折極端點。

3兩個最重要的旋鈕：控制「訊號多還是少」

新手其實不用動，但你如果覺得訊號太多太雜、或太少太慢，就是調這兩個。

取樣週期 Sampling Period（預設 100）

趨勢線要參考多少根K棒。調大→線更平滑穩定、訊號更少更慢；調小→線更靈敏、訊號更多更快。

區間倍率 Range Multiplier（預設 3）

趨勢線的容忍範圍有多寬。調大→要漲/跌比較多才翻轉，訊號少而穩（過濾雜訊）；調小→一點波動就翻轉，訊號多而雜。

一句話：兩個都調大 → 訊號少、穩、慢；都調小 → 訊號多、雜、快。覺得被雜訊掃來掃去就往大調，覺得太鈍反應太慢就往小調。

4漲／跌 訊號怎麼看

漲（綠、在K棒下方）＝趨勢翻成漲勢，偏多的參考點。跌（紅、在K棒上方）＝趨勢翻成跌勢，偏空的參考點。 英文版會顯示 Buy / Sell。

訊號是「參考時機」不是「保證」。翻轉訊號在盤整時容易來回被巴，最好搭配你自己的判斷（例如只做順著大方向的訊號），不要每個都照單全收。

5⭐ 星星：兩種模式

星星跟漲跌標籤是分開的兩套東西，用來抓「頂／底」。有兩種模式，設定裡用「★ 只標最高/最低點」切換。

🎯 只標最高/最低點（預設）

整段只在真正的大頂、大底各冒一顆⭐，畫面最乾淨。缺點：要等頂/底確認，星會慢幾根K才出現（但位置很準）。靈敏度由「最高/最低點靈敏度」（預設 30）控制，越大只抓越大的頂底。

⚡ 即時星（取消上面那個勾）

反轉就馬上冒星、最快，但星較多。由「最高點星／最低點星靈敏度」（各預設 3）控制，越小越靈敏星越多。
新手建議維持預設「只標最高/最低點」，畫面乾淨、只看大轉折就好。

6🌈 力道濃淡（預設已開）

這個功能預設幫你打勾了：同樣是漲，K棒越亮＝這根力道越強、越暗＝越弱（跌也一樣，紅色越強越亮）。讓你不只看方向，還看得出「動能強不強」。

示意圖：由暗到亮＝力道由弱到強（左：漲/綠　右：跌/紅）

🤍 最強勢的漲用亮白色

這個預設不打勾（留給你自己決定）。勾了之後，漲到最強的K棒會變亮白色（只適合黑底圖表，白底會看不到）。需要先開「力道濃淡」才有作用。

不想要濃淡？

把「🌈 顏色深淺表示力道」取消勾選，就回到單純的綠漲紅跌、不隨強弱變化，K棒也回復原本樣子。

7配色與語言

🟢🔴 漲跌配色

國際標準（預設）＝漲綠跌紅；台股/中港＝漲紅跌綠。習慣哪種就選哪種，趨勢線、K棒、標籤會一起換。

介面語言 / 出哪些訊號

語言可切繁中（漲/跌）或English（Buy/Sell）。「出現哪些訊號」可選漲跌都要（預設）、只出現漲、或只出現跌。

8設定警報（手機提醒）

想在出訊號時收到推播，就建立警報。

  1. 點圖表右上角鬧鐘 ⏰ → 建立警報。
  2. 「條件」第一格選 AI_漲_跌3 這個指標。
  3. 第二格挑你要的：漲跌都要（漲、跌都通知）、漲訊號、跌訊號、或 ★ 星星（都要/買/賣）。
  4. 按建立。之後出訊號就會推播。
這個指標本身用的是「具名警報條件」，所以第二格直接選你要的那一個就好，不用選「任何 alert() 函式呼叫」。想只收星星就選「★ 星星」，想只收漲跌就選「漲跌都要」。

9新手一定要知道的幾件事

  1. 穩定 vs 即時（收盤確認）。預設「收盤確認」是勾著＝穩定：等這根K棒走完才出圖示，不會亂跳。取消勾＝即時：圖示馬上出，但會重繪（可能先出現又消失/反轉）。新手建議維持穩定。
  2. 星會慢幾根K。「只標最高/最低點」要等頂/底確認，星會晚幾根出現，這是正常的（換來位置更準）。
  3. 盤整時訊號容易來回。沒有方向的時候翻轉訊號會多且容易錯，覺得雜就把兩個旋鈕往大調。
  4. 先回測再實戰。用歷史回放走幾十筆，確認你能接受它的節奏，再用小資金上場。
  5. 它是輔助不是命令。幫你看方向、標時機，最後怎麼下單是你的決定。

?常見問題

訊號怎麼一直翻來翻去、很多假訊號？

多半是盤整或旋鈕太靈敏。把「取樣週期」和「區間倍率」往大調（例如週期 150、倍率 4），訊號會變少變穩。

為什麼圖示會先出現又消失？

那是即時模式（收盤確認沒勾）造成的重繪。把「收盤確認」勾起來（穩定），等K棒走完才出圖示就不會亂跳。

星星為什麼比較慢才出現？

因為「只標最高/最低點」要等頂/底確認（左右各看 N 根），所以會晚幾根K，換來位置準準壓在最高/最低那根。想要快就取消它、改用即時星。

K棒顏色有的亮有的暗，是壞了嗎？

不是，那是力道濃淡（預設開）：亮＝這根力道強、暗＝弱。不想要就取消「🌈 顏色深淺表示力道」，回到單色。

我是台股習慣，紅漲綠跌可以嗎？

可以，把「🟢🔴 漲跌配色」改成台股/中港（紅漲綠跌）即可，全部會一起換。

可以直接照訊號無腦下單嗎？

不建議。它是輔助工具會出錯，請先歷史回放與小資金測試，確認節奏再決定怎麼用。
