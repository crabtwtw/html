0怎麼把指標加到圖表上（僅限邀請）

這是僅限邀請（Invite-only）的指標，作者授權你的帳號後就會出現在你的清單裡，不用貼程式碼。

  1. 先確認已被作者授權。授權完成後這個指標才會出現在你的清單；找不到就先聯絡作者。
  2. 打開 TradingView 圖表，點上方工具列 「指標 Indicators（fx）」。
  3. 左側點 「僅限邀請的腳本 / Invite-only scripts」分頁。
  4. 找到這個指標，點它就加到圖表上。要調整就點名稱旁的 齒輪 ⚙️。
💡 這是當沖／短線取向的工具，建議在 1～15 分鐘週期看。搭配你的「世界開盤時間」一起用，抓大波段時段更有方向。

2這個指標會幫你做什麼

① 自動找訊號

用 AI 趨勢偵測，幫你標出可能的多／空（漲／跌）進場點。

② 算好數字

自動算進場、止損、兩個止盈，還給你建議槓桿。

③ 畫在圖上

紅框＝風險、綠框＝獲利，一眼看懂這筆的賺賠範圍。

④ 推播提醒

可把訊號推到 Telegram，不用一直盯盤。

3最重要的一步：選「訊號來源」

這是全指標最關鍵的設定，決定它用哪種邏輯抓訊號。新手先選順勢就好。

🟢 順勢（新手推薦）

跟著趨勢方向做，訊號較穩、勝率較高。標記是實線。不知道選哪個就選這個。

🔴 反轉

在轉折處逆勢搶反彈／回落，賺得快但勝率天生較低。標記是虛線。進階再用。

⭐ 只看強高低點

只標出特別強的高低轉折點，訊號少而精，當參考位很好用。
相關細節設定：樞紐強度（預設 20，越大越嚴格、訊號越少）、反轉確認根數（預設 5，多等幾根確認更穩）、趨勢方向濾網（只做順著大方向的單）。新手照預設即可。

4一筆交易怎麼看：多單 vs 空單

多單和空單的紅框綠框位置是上下相反的，記住一個原則就好：綠框永遠在你賺錢的方向、紅框永遠在你賠錢的方向。

做多（漲）：綠框在上（止盈）、紅框在下（止損）
做空（跌）：紅框在上（止損）、綠框在下（止盈）

RR（風險報酬比）怎麼看：止盈1 RR1.5＝這段賺的是你願意賠的 1.5 倍；止盈2 RR2.5＝2.5 倍。常見做法是到止盈1 先出一半、剩下抱到止盈2，並把止損往進場價移動（減少風險）。

5策略標記：順 / 逆 / 強，實線 vs 虛線

每個訊號旁會有一個小標記，告訴你這個訊號是哪種策略產生的，讓你知道它的「性格」。

順

順勢訊號，實線框。相對穩健。

逆

反轉訊號，虛線框。搶轉折、風險較高。

強

強高／低點，重要的轉折參考位。
口訣：實線＝順勢（穩）、虛線＝反轉（險）。看到虛線框就知道這是搶反轉，要更小心、部位放小。另外圖上還有「強高／弱低參考線」，那只是資訊參考，不是進場訊號。

建議槓桿只是「緩衝後的參考值」。新手請更保守，抓 3～8 倍就好；槓桿越高，一個止損就傷越重。

7風險管理設定（進階，先照預設）

這些決定止損／止盈畫多遠、槓桿怎麼建議。新手照預設就好，等熟了再微調。

止損（ATR）

用 ATR（波動度）算止損距離，預設 14 / 1.5 / 2.5%。波動大時止損會自動放寬，避免被雜訊掃出場。

止盈目標（RR）

兩個止盈用風險報酬比設定，預設約 RR 1.5 / 2.5。想更快落袋就把 RR 調小、想搏大就調大。

槓桿緩衝

預設 50 / 0.7：先算出理論槓桿，再乘上緩衝係數變保守，給你一個較安全的建議值。

只顯示最新框

預設 開。只畫最近一個訊號框，畫面乾淨。想回顧歷史訊號再關掉。

8把訊號推到 Telegram

不想一直盯盤？讓它在出訊號時主動推到你的 Telegram。

  1. 設定裡把警報格式選成 Telegram（或 JSON，看你的機器人要吃哪種），需要時填訊息前綴讓機器人辨識。
  2. 點圖表右上角鬧鐘 ⏰建立警報，條件選這個指標、觸發選 「任何 alert() 函式呼叫」。
  3. 把警報的Webhook接到你的 Telegram 機器人（依你機器人的說明設定）。
  4. 之後一出訊號，方向／進場／止損／止盈就會自動送到你的 Telegram。
和「開盤前提醒」一樣，Pine 只負責發訊號，真正送出要靠 TradingView 的警報；沒建警報就不會推。

9新手一定要知道的幾件事

  1. 框會晚幾根K棒才出現。為了可靠，指標會等訊號確認才畫，所以不會剛好標在最高／最低點——這是刻意的，不是誤差。
  2. 反轉（虛線）勝率天生較低。搶轉折偶爾很甜，但錯的次數也多，部位要放小。
  3. 先回測再實戰。用 TradingView 的歷史回放（K棒重播）走幾十筆，確認你能接受它的節奏再上場。
  4. 槓桿保守。新手 3～8 倍，寧可少賺，先活下來。
  5. 訊號是輔助不是命令。它幫你找位置、算數字，最後下不下單、下多少，是你的決定。

?常見問題

訊號為什麼沒標在最高／最低點？

因為框會等訊號確認才畫，會晚幾根K棒，這是為了可靠、避免假訊號。它本來就不保證抓在極端點。

紅框和綠框到底哪個是賺、哪個是賠？

綠框永遠是獲利方向（到止盈）、紅框永遠是風險方向（到止損）。做多時綠框在上、做空時綠框在下，位置會相反，但顏色意義不變。

建議槓桿可以直接照用嗎？

那是「緩衝後的參考值」，不是叫你一定要開這麼大。新手請更保守，3～8 倍就好，槓桿越高一次止損傷越重。

反轉模式感覺很準，可以一直用嗎？

反轉（虛線）勝率天生較低，甜的時候很甜、錯的時候也多。建議部位放小、以順勢為主，反轉當輔助。

Telegram 收不到推播？

先確認有在 TradingView 建立警報（條件選 Any alert() function call）並把 webhook 接到你的機器人。只在設定裡選 Telegram 格式、沒建警報是不會送的。

可以直接照訊號無腦下單嗎？

不建議。它是輔助工具，會出錯。請先用歷史回放與小資金測試，確認你能接受它的節奏，再決定怎麼用。
