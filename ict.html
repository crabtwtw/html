5實戰怎麼看(新手三招)

① 先看琥珀線判多空

價格站在琥珀線上方 → 當天偏多,優先找做多;跌到下方 → 偏空,優先找做空。盤中拉回這條線有沒有守住,常是續強 / 轉弱的線索。

② 只在「進行中」的時段找機會

看到 ● 圓點(進行中)+ 外框變粗,代表現在是高流動性時段,值得專心。看到「紐約午休」在跑通常先別急(容易盤整);倒數離下一個時段還很久,就代表空窗,可以休息別亂做。

③ 把時段的高 / 低線當關卡

價格突破前一個時段的高或低,常是「掃流動性」的動作,是 ICT 很看重的訊號。這些線可當壓力、支撐或停利目標。

你做的黃金 / BTC:最活躍的通常是倫敦(台北 14:00)和紐約早盤(台北 20:30)。新手先只盯這兩段 + 琥珀開盤線,其他時間少碰,通常比較穩。

!注意事項

• 倒數秒數不是每秒固定跳——TradingView 有新報價才重算,活躍商品跳得順,冷門/收盤可能卡幾秒,屬正常。

• 桌機 Windows 看不到國旗,所以名稱用「●」圓點,這是字型限制(手機才顯示旗子)。

• 時段時間是慣例不是絕對——紐約早盤用 08:30 是為了對齊美國數據 + AM Silver Bullet,適合金 / BTC,你要別的時間可自行修改。

• 面板語言不能即時切換(Pine 限制),所以分成中文檔、英文檔兩個版本。

• 它是輔助工具,不是買賣訊號——幫你抓時間與關鍵價位,進出場仍要搭配你的策略與風控。

★一頁小抄

  • ● 圓點 = 這個時段正在進行中。
  • 琥珀線 = 真實日開盤;上方偏多、下方偏空。
  • 倒數 = 下一個時段還有多久開盤(時:分:秒)。
  • 方框太濃 → 調各時段透明度數字(越大越淡),或勾「只描邊」。
  • 金 / BTC 重點 → 倫敦(台北 14:00)、紐約早盤(台北 20:30)。
  • 高 / 低線 = 支撐壓力與流動性目標。
